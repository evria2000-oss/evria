# VStream — نسخه اولیه

این پروژه یک نمونه اولیه برای تماشای یک ویدئو توسط دو نفر، چت متنی و هماهنگی پخش/توقف/جابه‌جایی زمان است.

## اجرا روی کامپیوتر ویندوز

1. Python 3.10 یا جدیدتر نصب باشد.
2. این پوشه را در VS Code باز کن.
3. در ترمینال VS Code اجرا کن:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

4. کد اتاق را تعیین کن (در PowerShell):

```powershell
$env:ROOM_CODE="246810"
```

5. سرور را اجرا کن:

```bash
uvicorn main:app --reload
```

6. در مرورگر برو به `http://127.0.0.1:8000`

برای آزمایش دونفره روی یک شبکه محلی می‌توان از آدرس IP کامپیوتر استفاده کرد. برای دوستت از راه دور، باید پروژه روی هاست آنلاین Deploy شود.

## انتشار روی Render

1. یک حساب Render و یک مخزن GitHub بساز.
2. فایل‌های همین پوشه را در مخزن GitHub بارگذاری کن.
3. در Render گزینه New > Web Service را بزن و مخزن را متصل کن.
4. Render فایل `render.yaml` را می‌خواند؛ Build و Start command از قبل تنظیم شده‌اند.
5. بعد از Deploy، آدرس HTTPS سایت را باز کن.
6. مقدار متغیر محیطی `ROOM_CODE` در تنظیمات Render را به یک کد خصوصی که فقط دو نفر می‌دانند تغییر بده.

## محدودیت‌های مهم نسخه اولیه

- این نسخه فقط یک فایل ویدئو می‌پذیرد.
- فقط دو اتصال هم‌زمان در اتاق پذیرفته می‌شود.
- چت و وضعیت پخش فعلاً در حافظه سرور هستند؛ با راه‌اندازی مجدد پاک می‌شوند.
- فضای دیسک رایگان هاست‌ها معمولاً پایدار نیست. برای اینکه ویدئو بعد از Restart/Deploy هم باقی بماند، باید فضای ذخیره‌سازی دائمی یا فضای ذخیره‌سازی ابری جداگانه تنظیم شود.
- سرویس رایگان Render ممکن است پس از مدتی بی‌استفاده‌بودن به خواب برود؛ بنابراین برای تماشای بدون وقفه مناسبِ تضمین‌شده نیست.
- این نسخه برای نمونه و یادگیری است، نه استفاده عمومی حساس. برای انتشار واقعی باید احراز هویت امن‌تر، محدودیت نرخ پیام، اعتبارسنجی فایل و ذخیره‌سازی امن اضافه شود.
- این پروژه ویدئو را به صورت فایل مشترک پخش می‌کند؛ همگام‌سازی در اینترنت ممکن است کمی تأخیر داشته باشد و مرورگرها ممکن است پخش خودکار را مسدود کنند.
